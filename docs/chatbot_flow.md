# 챗봇 대화 흐름 설계도 — 포용적 개편판

## 설계 원칙
- 최소 3가지 입력만으로 최대 범위 탐색
- 장애/비장애 등 경계 없이 모든 사용자 포함
- "혹시 해당될 수 있다" 방식으로 접근

---

## 전체 흐름

```
[시작]
  │
  ▼
① 나이 입력 (필수)
  │
  ▼
② 거주 지역 선택 (필수)
  시·도 → 시·군·구
  │
  ▼
③ 지금 가장 어려운 점 선택 (필수, 복수 선택 가능)
  ☐ 생활비·식비가 부족해요
  ☐ 병원비·건강이 걱정돼요
  ☐ 주거가 불안정해요
  ☐ 교육비·돌봄이 필요해요
  ☐ 취업·일자리가 필요해요
  ☐ 사업·자영업이 어려워요
  ☐ 가족을 돌봐야 해요
  ☐ 갑작스러운 위기 상황이에요
  ☐ 건강·신체적으로 불편함이 있어요
  │
  ▼
④ 현재 일하는 상황 (선택)
  더 정확한 결과를 원하시면 선택해 주세요
  ○ 직장에 다니고 있어요
  ○ 자영업·사업을 하고 있어요
  ○ 소상공인이에요
  ○ 일자리를 찾고 있어요
  ○ 학생이에요  ○ 기타
  │
  ▼
⑤ 가족·돌봄 상황 (선택)
  ○ 혼자 살고 있어요
  ○ 배우자와 둘이 살아요
  ○ 아이와 함께 살고 있어요
  ○ 혼자 아이를 키우고 있어요
  ○ 어르신 가족을 돌보고 있어요
  ○ 아픈 가족이 있어요
  │
  ▼
⑥ 소득 수준 (선택 — 몰라도 됩니다)
  ○ 잘 모르겠어요 (소득 무관 서비스 우선 안내)
  ○ 거의 없어요
  ○ 중위소득 50% 이하
  ○ 중위소득 50~100%
  ○ 중위소득 100% 이상
  │
  ▼
⑦ 복지 서비스 탐색 중...
  (복지로 API + 경기도 API 광범위 조회)
  │
  ▼
⑧ 결과 출력 — 3단계 분류
  ┌──────────────────────────────────────┐
  │ ✅ 지금 바로 신청 가능      N건      │
  │ 🔍 해당 가능성 있음        N건      │
  │ 📌 미리 알아두면 좋은 것   N건      │
  └──────────────────────────────────────┘

  각 서비스 카드:
  ┌──────────────────────────────────────┐
  │ 서비스명                             │
  │ 소관 부처                            │
  │ 나에게 해당되는 이유: ○○○           │
  │ 지원 내용: ○○○                     │
  │              [신청하기 →]            │
  └──────────────────────────────────────┘
  │
  ▼
⑨ 결과 Draft 저장
   → reports/drafts/ 로컬 저장
  │
  ▼
[다시 조회] 또는 [종료]
```

---

## 포용적 설계 적용 지점

| 기존 방식 | 새 방식 |
|----------|---------|
| "장애인입니까?" | "건강·신체적으로 불편함이 있으신가요?" |
| 자격 미달 시 결과 없음 | 가능성 있음 / 미리보기로 항상 결과 제공 |
| 소득 필수 입력 | "잘 모르겠어요" 선택 시 소득 무관 서비스 우선 안내 |
| 단일 조건 매칭 | 복수 상황 선택 → 교차 서비스 발굴 |

## 확정 문제

### 핵심 한 줄
> **복지가 필요한 사람이 자신에게 맞는 서비스를 찾지 못해, 받을 수 있는 혜택을 놓치고 있다.**

### 상세 설명

```
WHO    대상자  : 서울·경기 거주, 복지 서비스가 필요하지만 정보 접근이 어려운 시민
                 (고령자, 저소득층, 한부모, 장애인, 청년 구직자 등)

WHAT   문제    : 중앙정부 + 지자체에 걸쳐 수백 개의 복지 정책이 존재하지만
                 개인 상황에 맞는 서비스를 스스로 찾기가 극히 어렵다

WHY    원인    : 1) 정책 정보가 복지로·보조금24·서울시·경기도 등 여러 기관에 분산
                 2) 자격 조건이 나이·소득·가족 상황·지역 등 복합 기준으로 구성
                 3) 행정 용어가 어렵고, 신청 경로가 기관마다 다르다

IMPACT 결과   : 수급 자격이 있음에도 몰라서 신청 못 하는 '복지 사각지대' 발생
                 → 실질적 생활 어려움 지속, 사회 안전망 기능 저하
```

### AI가 이 문제를 풀기에 적합한 이유
1. **개인화** — 나이·지역·소득·가족·상황이 조합되는 경우의 수가 수천 가지 → 규칙 기반 온톨로지 + NLP로 자동 매칭
2. **반복 처리** — 수백 개 정책을 매번 사람이 검토할 수 없음 → 지식 그래프가 순간 처리
3. **언어 이해** — "집이 없어요", "남편이 갑자기 실직했어요" 등 비정형 문장 → NER + 의도 분류로 구조화
4. **24시간 접근** — 야간·주말에도 즉시 안내 가능 → 주민센터 방문 없이 1차 정보 제공

## 범위 (Scope)

### In-Scope ✅
- 서울특별시 + 경기도 거주자
- 중앙정부(복지로·보조금24) + 서울시·경기도 복지 정책
- 자격 판단 3단계: 신청 요건 충족 / 가능성 있음 / 미래 대비
- 자연어 입력 + 단계별 선택 두 가지 경로

### Out-of-Scope ❌
- 실제 신청 대행 (법적 제한)
- 수급 확정 보장 (기관 심사 필요)
- 타 시·도 (데이터 미확보)
- 개인정보 외부 서버 저장 (보안 원칙)

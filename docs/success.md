# MVP 성공 기준 (Success Criteria)

> 작성일: 2026-06-08  
> 프로젝트: 아테나 복지서비스

---

## 핵심 성공 기준 — 단 한 문장

> **"복지 정보를 몰랐던 서울·경기 시민이 아테나에 자신의 상황을 입력했을 때,  
> 실제로 신청 가능한 서비스를 3분 안에 찾아 신청 페이지까지 도달한다."**

---

## 성공 기준 분해

### 핵심 지표 (Must Have)

| 지표 | 기준값 | 측정 방법 |
|------|--------|----------|
| 자격 판단 정확도 | DEFINITE 결과가 실제 자격 요건과 일치율 **90% 이상** | 10개 테스트 케이스 검증 |
| 응답 시간 | 입력 → 결과 표시 **3초 이내** | API 응답 시간 측정 |
| NLP 인식률 | 자연어 입력에서 나이·지역 추출 성공률 **85% 이상** | 47개 자동 테스트 |
| 법적 준수 | 개인정보 외부 전송 **0건** | 네트워크 로그 감사 |
| 면책 문구 | 모든 결과 화면에 **반드시 표시** | UI 검수 |

### 사용자 경험 지표 (Should Have)

| 지표 | 기준값 |
|------|--------|
| 단계별 입력 완료율 | 시작한 사용자의 70% 이상이 결과까지 도달 |
| NLP 입력 성공률 | 자연어 입력 사용자의 80% 이상이 지역 보완 없이 결과 수령 |
| 신청 버튼 클릭률 | DEFINITE 결과 카드의 "신청하기" 버튼 클릭률 30% 이상 |

---

## MVP 완료 체크리스트

### 기능
- [x] 단계별 입력 (7단계: 나이·지역·상황·직업·가족·성별·소득)
- [x] 자연어 NLP 입력 (kiwipiepy 형태소 분석)
- [x] 온톨로지 자격 판단 3단계 (DEFINITE / POSSIBLE / FUTURE)
- [x] 20개 핵심 정책 데이터 (복지로·보조금24·서울·경기)
- [x] 필요 서류 목록 자동 제시
- [x] 신청 URL 직접 연결
- [x] 성별 특화 서비스 (여성가족부·보훈)

### 법적·보안
- [x] 개인정보 로컬 기기 전용 저장
- [x] 외부 서버 전송 없음
- [x] 면책 문구 UI 표시
- [x] MatchLevel 과장 표현 제거
- [x] 공공누리 출처 표시 메타데이터

### 품질
- [x] 자동화 테스트 47개 통과
- [x] 7개 페르소나 케이스 검증
- [ ] 실제 사용자 5명 이상 테스트 (베타)
- [ ] 복지로 API 실시간 연동 (키 발급 후)

---

## MVP가 아닌 것 (Explicitly Out)

- 실제 신청 대행 처리
- 수급 여부 법적 확인
- 서울·경기 외 지역
- 회원가입 / 이력 저장
- 카카오 로그인

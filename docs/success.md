# MVP 성공 기준 (Success Criteria)

> 작성: 아테나 | 날짜: 2026-06-08 | 브랜치: feature/athena

---

## 핵심 성공 기준 — 단 한 문장

> **"사용자가 자기 상황을 입력하면 3분 안에 신청 가능한 서비스를 찾고,
> 더 자세하고 정확한 담당 업무 부서와 바로 연결된다."**

---

## 성공 기준 분해

### 반드시 되어야 하는 것 (Must Have)

| 기준 | 목표 |
|------|------|
| 서비스 찾는 시간 | 입력 후 **3분 이내** 결과 확인 |
| 신청 가능 여부 표시 | 맞는 복지 서비스 **즉시** 화면 표시 |
| 담당 부서 연결 | 재검색 없이 **앱 안에서 전화 연결** |
| 자격 판단 정확도 | 실제 조건과 일치율 **90% 이상** |
| 개인정보 보호 | 외부 서버 전송 **0건** |

### 있으면 더 좋은 것 (Should Have)

| 기준 | 목표 |
|------|------|
| 자연어 입력 인식 | 말하듯 입력해도 상황 파악 |
| 모바일 최적화 | 어르신도 쉽게 쓸 수 있는 UI |
| 서류 안내 | 신청에 필요한 서류 목록 자동 표시 |

## MVP 완료 체크리스트

### 핵심 기능
- [x] 단계별 입력 (나이·지역·상황·직업·가족·소득)
- [x] 자연어 입력 (말하듯 검색)
- [x] 복지 서비스 자동 매칭 (신청 가능 / 가능성 있음 / 미래 대비)
- [x] 담당 기관 전화번호 표시
- [x] 신청 URL 연결
- [x] 필요 서류 목록 안내

- [ ] 실제 사용자 5명 이상 테스트

- [ ] 전화 바로 걸기 버튼 (tel: 링크)

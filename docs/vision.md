## 핵심 비전 — 한 문장

> **"복지 정보를 몰라서 혜택을 못 받는 사람이 없어지는 세상,
> 앱 하나로 즉시 내 복지 혜택을 확인하고 담당자와 바로 연결되는 세상"**

---

## 미래상 — 이 앱이 완성된 후

### 변화 1 — 즉시 확인
```
Before: 복지 혜택이 있는지 몰라서 그냥 포기
After:  앱을 열면 나와 관련된 복지 혜택을 즉시 확인
```

### 변화 2 — 전화 연결
```
Before: 담당 부서 전화번호를 다시 검색해야 함
After:  앱 안에서 바로 전화 연결 — 재검색 없음
```

### 변화 3 — 행정센터 방문 없이
```
Before: 신청 가능한지 알려면 직접 행정센터 방문 필요
After:  휴대폰으로 신청 가능 여부 즉시 파악
```

## 성공한 미래의 사용자 모습

### 페르소나 — 59세 남성 독거 어르신
> "아프고 생활비도 없는데 어디에 신청해야 할지 몰랐어요.
> 아테나 앱에서 나이·상황 입력했더니 의료지원금이랑 생활보조금을
> 신청할 수 있다고 나왔어요.
> 담당 부서 전화번호도 바로 있어서 바로 전화했어요."

---

## 우리가 지키는 원칙

1. **간단하고 직관적** — 어르신도 혼자 쓸 수 있어야 한다
2. **즉시 연결** — 정보만 주고 끝이 아니라 전화까지 연결
3. **꼼꼼한 정보** — 행정센터에서 간과하는 것도 앱이 챙긴다
4. **개인정보 보호** — 기기 밖으로 나가지 않는다

# VISION DRAFT — 아테나 복지 정보 시스템
> 이 파일은 작업 과정에서 나온 VISION 요소를 누적 정리하는 전용 파일입니다.
> 최종 확인 후 VISION.md 로 확정합니다.

---

## 핵심 가치 (Core Value)
- 개인정보 노출 없이 맞춤형 복지 혜택을 받을 수 있도록 한다
- 복잡한 복지 시스템을 누구나 쉽게 접근할 수 있게 단순화한다
- 경제적 부담을 덜고 안정적인 생활을 지원한다
- 장애/비장애 등 경계 없이 모든 국민이 해당 가능성을 탐색할 수 있도록 한다

## 대상 사용자 (Target)
- 대한민국 모든 국민 — 경계 없이 전체 포함
- 자영업자·소상공인 (환급금·지원금 별도 트랙)
- 취약계층 포함 — 단, 전용이 아닌 진입점으로 설계

## 서비스 방향 (Direction)
- 챗봇형 대화 인터페이스 — 질문에 답하면 맞춤 결과 자동 도출
- 전국 일간지 + 17개 광역시·도 지자체 신문 복지 정보 실시간 취합
- 복지로 API 연동 — 생계·의료·주거·교육·보조금환급금 5분류 매칭
- 결과는 Draft 저장 후 사용자 확인 → 신청 링크 직접 연결

## 보안 원칙 (Security)
- 개인정보는 로컬 세션에만 존재, 외부 서버 미전송
- 에이전트 자율 실행 금지 — 반드시 아테나님 승인 후 실행
- 결과물은 Draft 상태로만 생성

# 이상적 사용자 시나리오 (User Scenario)

> 작성: 아테나 | 날짜: 2026-06-08 | 브랜치: feature/athena
> 형식: 사용자가 OO할 때 → 서비스가 OO해주고 → 결국 OO하게 된다

---

## 핵심 시나리오 — 59세 남성 독거 어르신

```
사용자가  59세 남성으로 혼자 살면서 아프고 생활비도 없어
          막막한 상황에서 아테나 앱을 열었을 때

서비스가  나이(59세)·혼자 삶·건강 어려움·생활비 부족을 인식하고
          의료지원금·생활보조금 신청이 가능하다고 즉시 안내하며
          담당 부서 전화번호를 앱 안에서 바로 연결해주고

결국       행정센터에 가지 않고도 휴대폰으로
          의료지원·생활보조금 두 가지를 한 번에 신청하게 된다
```

---

## 시나리오 2 — 생활이 어려운 가족

```
사용자가  가족 중 누군가 복지 혜택을 받을 수 있는지 궁금하지만
          어디에 물어봐야 할지 모를 때

서비스가  가족 상황(나이·지역·소득·가족 구성)을 단계별로 입력받아
          해당하는 복지 서비스를 한눈에 보여주고
          신청 가능 여부와 담당 전화번호를 바로 제공하고

결국       주변인에게 물어볼 필요 없이 앱 하나로 해결하게 된다
```

---

## 시나리오 3 — 자연어로 검색

```
사용자가  "생활비가 없고 아파요. 서울 삽니다"라고 그냥 말하듯 입력할 때

서비스가  입력 문장에서 상황·지역을 자동으로 파악하고
          맞는 복지 서비스를 즉시 안내하며
          담당 기관 전화번호까지 화면에 표시하고

결국       복잡한 메뉴 탐색 없이 말하듯 입력만 해도
          3분 안에 신청할 서비스를 찾게 된다
```

---

## 공통 흐름

```
앱 실행
  ↓
상황 입력 (자연어 OR 단계별 선택)
  ↓
복지 서비스 자동 매칭
  ↓
신청 가능 여부 즉시 표시
  ↓
담당 기관 전화번호 바로 연결
  ↓
사용자가 직접 신청 → 혜택 수령
```

# 이상적 사용자 시나리오 (User Scenario)

> 작성일: 2026-06-08  
> 프로젝트: 아테나 복지서비스  
> 형식: '사용자가 OO할 때 → 서비스가 OO해주고 → 결국 OO하게 된다'

---

## 시나리오 1 — 한부모 가구 (핵심 시나리오)

```
사용자가  혼자 아이를 키우며 생활비가 부족한 상황에서
          "혼자 아이 키우는데 생활비가 없어요. 서울 노원구 삽니다"라고 입력할 때

서비스가  NLP로 상황(한부모·생활비 위기·서울 노원구)을 자동 인식하고
          온톨로지 자격 판단으로 기초생활수급·한부모가족지원·아동돌봄쿠폰을 DEFINITE로,
          서울긴급복지·경력단절여성지원을 POSSIBLE로 즉시 안내해주고

결국       몰랐던 한부모가족 지원금을 신청해 매달 생활비 보조를 받게 된다.
```

---

## 시나리오 2 — 은퇴 준비 중장년 (자연어 입력)

```
사용자가  58세에 회사를 그만두고 앞으로 뭘 받을 수 있는지 막막한 상황에서
          "58세인데 이번에 퇴직했어요. 경기도 수원 삽니다. 국민연금은 언제 받나요"라고 입력할 때

서비스가  나이(58세)·지역(경기 수원)·상황(퇴직·구직)을 인식하고
          실업급여·중장년 취업지원을 DEFINITE로,
          기초연금(65세 도달 시)을 FUTURE로 구분해 시기별 로드맵을 제시하고

결국       실업급여를 바로 신청하고, 65세 기초연금 신청 시점도 미리 파악하게 된다.
```

---

## 시나리오 3 — 고령 독거노인 (가족 대리 조회)

```
사용자가  72세 어머니를 위해 딸이 어떤 도움을 받을 수 있는지 알고 싶을 때
          단계별 입력에서 나이 72, 서울, 혼자 삶, 건강 어려움을 선택할 때

서비스가  노인장기요양보험·노인일자리·기초연금을 DEFINITE로,
          의료급여를 POSSIBLE로 안내하며
          각 서비스의 신청 서류(주민등록등본·의사소견서)와 신청처(주민센터·국민건강보험공단)를 명시하고

결국       딸이 어머니 대신 서류를 준비해 한 번에 여러 서비스를 신청하게 된다.
```

---

## 시나리오 4 — 청년 구직자 (경기도)

```
사용자가  24세 대졸 미취업 상태로 경기도에 거주하며 지원받을 수 있는 것을 모를 때
          "취업 준비 중인 24살인데 경기도 성남시 살아요"라고 입력할 때

서비스가  경기도 청년기본소득·청년 취업지원금·서울 청년월세(경기 거주 불가)를 구분해
          경기 거주자에게만 해당하는 서비스를 정확히 DEFINITE로 필터링하고

결국       경기청년기본소득 분기별 25만원을 신청해 구직 기간 생활비를 보조받는다.
```

---

## 공통 성공 패턴

```
입력 (자연어 or 단계별 선택)
  ↓
NLP 분석 (나이·지역·상황·가족·직업 추출)
  ↓
온톨로지 자격 판단 (DEFINITE / POSSIBLE / FUTURE)
  ↓
필요 서류 + 신청처 + 신청 URL 제공
  ↓
사용자가 스스로 신청 → 혜택 수령
```

## 실패 시나리오 (피해야 할 상황)

| 실패 유형 | 원인 | 방지책 |
|----------|------|--------|
| 자격 없는 서비스를 "신청 가능"으로 표시 | 조건 누락 | 온톨로지 조건 검증 + `is_verified` 필드 |
| 지역 오인식으로 타 지역 서비스 안내 | NER 오류 | 지역 보완 UI + 명시적 확인 |
| 민감정보(장애·질병) 노출 | 저장 오류 | 로컬 기기 전용, 외부 전송 없음 |
| "수급 확정"으로 오해 | 표현 문제 | MatchLevel 표현 → "요건 충족 가능성 높음" |
